# Surplus Food Rescue & Donation Platform

Advanced SEML project based on the approved build guide.

## Phase 1 — Foundation
- React + Vite frontend
- Express backend
- Docker Compose
- PostgreSQL/PostGIS
- Redis
- Prisma
- API v1 health endpoint
- Separate files/modules

## Start
```bash
docker compose up -d
cd backend && npm install && npm run dev
cd ../frontend && npm install && npm run dev
```
